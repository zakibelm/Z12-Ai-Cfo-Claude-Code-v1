# Audit / red team du 20 novembre 2026 — correctifs appliqués

| # | Constat | Correctif |
|---|---------|-----------|
| 1 | La connexion Google contournait l'inscription sur invitation | `auth_google._google_signup_allowed` : compte existant, mode `open` ou `GOOGLE_ALLOWED_EMAILS` ; échec = refus |
| 2 | Bearer non révocable, logout sans révocation, JWT en clair en base | Bearer `iss=phoenix-auth` exige un `jti` actif ; `POST /api/auth/logout` révoque la session (GET retiré) ; la base stocke l'empreinte SHA-256 |
| 3 | Limitation de débit sur l'IP du proxy | `--proxy-headers`, nginx réécrit `X-Forwarded-For` (real_ip), limite ajoutée sur `/reset-password`, hash factice au login |
| 4 | Dépendances vulnérables | PyJWT, starlette, python-multipart, aiohttp, urllib3, cryptography, pillow, anyio, multidict, yarl mis à jour ; PyPDF2 remplacé par pypdf |
| 5 | Chaîne de déploiement | `npm ci` sans repli, backend non-root, plus de `root`/IP en dur dans la CI (secrets obligatoires) |
| 6 | Loi 25 | Suppression : compte Google, usage, budget, jetons de reset ; export : usage, budget, documents ; plus de mot de passe de base par défaut |
| 7 | Configuration | Compose transmet ADMIN_USER_IDS, REGISTRATION_MODE, SMTP_*, budgets ; filtre de modèles par défaut ; nginx : CSP, HSTS, server_tokens off |

Reste à faire côté exploitation : définir `SSH_HOST`, `SSH_USER` (non-root), `SSH_PRIVATE_KEY` dans GitHub ; scanner l'historique git complet du dépôt d'origine (gitleaks) ; confirmer que les clés OpenRouter enregistrées par utilisateur (`local_users.openrouter_key`) doivent être chiffrées.
